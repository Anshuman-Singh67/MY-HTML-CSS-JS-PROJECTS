## 🔐 2. Password Guessing Game

An interactive browser-based password guessing game built with **HTML, CSS, and JavaScript**.

The player attempts to guess a predefined password while the JavaScript logic processes the user's input and provides feedback.

#### ✨ Features

* Interactive password input
* Guess validation
* Instant feedback
* Attempt tracking
* Interactive buttons
* Simple and clean interface

#### 🛠️ Concepts Practiced

* DOM manipulation
* Event handling
* Conditional statements
* Functions
* Variables
* User input
* JavaScript logic

> This is an educational game and does not attempt to access or crack real passwords or accounts.
